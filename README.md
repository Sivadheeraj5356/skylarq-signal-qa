# Skylarq Signal QA

A client-side data-quality tool for Skylarq-style application-layer AI workflows. Paste company or people enrichment records and the tool flags duplicate identities, missing titles, invalid domains and stale enrichment dates before records feed WhatsApp agents or go-to-market workflows. It runs entirely in the browser and stores no data.

## Run

Open `index.html` in a browser. No server, dependency, or API key is required.

## Test

```bash
node test.js
```
